Welcome to **Mare Blog** — a minimalist personal space dedicated to web development, technical explorations, and daily thoughts.

This blog is designed around three core principles: **Simplicity, Performance, and Reader Experience**.

## ✨ Features & Reading Experience

- **⚡ Lightning Fast**: Powered by Astro for static generation, ensuring instant page loads and silky-smooth navigation.
- **🔍 Instant Search**: Integrated with **Pagefind** for super-fast full-text search directly in the browser without any backend servers.
- **🎨 Clean & Responsive Design**: Styled with Tailwind CSS to offer a seamless, distraction-free reading experience on all screen sizes, with automatic **Dark / Light mode** support.
- **💬 Interactive Discussions**: Integrated with **Giscus** (powered by GitHub Discussions) so readers can easily leave comments and share thoughts.
- **📡 Stay Updated via RSS**: Prefer feed readers? Subscribe via the built-in [RSS Feed](/rss.xml) to never miss an update.

## 🛜 Tech Stack

This site is built with modern, lightweight web technologies:

- **Framework**: [Astro](https://astro.build)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Search**: [Pagefind](https://pagefind.app)
- **Comments**: [Giscus](https://giscus.app)
- **Content Editing**: [Pages CMS](https://pagescms.org)
